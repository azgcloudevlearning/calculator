# C# console calculator

This is a simple calculator built for console to learn C# fundamentals.

---

## Features
- Basic operations: addition, substraction, multiplication and divisions
- Input validation and error handling (e.g, avoid division between zero)

---

## Getting started

### Prerequisits
- [.NET 10 SDK] (https://dotnet.microsoft.com/en-us/download/dotnet/10.0) installed on MacOS/Linux/Windows
- Git

### Installation
1. Clone the repository
```bash
git clone git@github.com:azgcloudevlearning/calculator.git
```

2. Navigate to the project folder

3. Run the program
```bash
dotnet run
```

## Usage
- Enter two number and operator (+ - * /)
- The calculator will display a result
- Example:
```bash
Enter first number: 50
Enter operator (+ - * /): *
Enter second number: 2
Result: 100
```
